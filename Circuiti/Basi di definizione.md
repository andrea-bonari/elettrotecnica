>[!note] Base tensione
>Un generico $n$-poli si dice definito su base tensione se è possibile imporre tutte le tensioni e ricavare tutte le correnti: $$\overrightarrow{i}=f(\overrightarrow{v})$$

>[!note] Base corrente
>Un generico $n$-poli si dice definito su base corrente se è possibile imporre tutte le correnti e ricavare tutte le tensioni: $$\overrightarrow{V}=g(\overrightarrow{i})$$

>[!note] Base mista
>Un generico $n$-poli si dice definito su base corrente se è possibile imporre un sottoinsieme di tensioni e correnti e ricavare tutte le altre.
